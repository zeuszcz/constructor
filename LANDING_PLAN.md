# План супер-продающего лендинга Omnia.AI

> **Цель документа:** дать команде пошаговый план — что должно быть на сайте, в каком порядке, какими словами и визуалом, чтобы:
> 1. Человек **остался** (не закрыл вкладку за 5 секунд)
> 2. Понял **что получит** (ясное value proposition)
> 3. Понял **зачем платить** (выгода и удобство)
> 4. Захотел **попробовать бесплатно** (низкий порог входа)
> 5. Конвертировался в **платящего** (upgrade после пробника)

> **Внимание:** документ описывает только то, что **видит и чувствует пользователь**. Внутренние стратегии (тарифная экономика, расходы, CAC) — НЕ публикуются на сайте.

## 0. Главные принципы и философия

### 0.1 5 «У» Каплза (4 U's + 1)

Каждый заголовок и подзаголовок на лендинге обязан проходить тест на:
1. **Useful** — Полезно: что конкретно человек получит
2. **Urgent** — Срочно: почему стоит сделать сейчас, а не «когда-нибудь»
3. **Unique** — Уникально: чем мы отличаемся от Tilda/Bitrix/студий
4. **Ultra-specific** — Конкретно: цифры, время, имена, не «много» и «быстро»
5. **Understandable** — Понятно: 12-летний ребёнок должен понять с первого чтения

### 0.2 Каркас сторителлинга: AIDA + PAS

- **A**ttention (Внимание) — hero-секция за 5 секунд
- **I**nterest (Интерес) — проблема + agitation
- **D**esire (Желание) — решение + социальный proof
- **A**ction (Действие) — CTA с минимальным трением

**PAS дублирует AIDA в каждой секции:**
- **P**roblem — болит ли это у клиента?
- **A**gitation — как именно болит, во сколько обходится
- **S**olution — как мы убираем боль

### 0.3 Психологические якоря для SMB-аудитории РФ 2026

| Якорь | Что делаем |
|---|---|
| **Социальное доказательство** | Отзывы с фото и именами, кейсы конкретных клиентов, число пользователей |
| **Авторитет** | 152-ФЗ соответствие, упоминания в Habr/VC.ru/РБК |
| **Дефицит** | Ограниченные слоты на VIP-онбординг, скидка только при оплате до конца дня |
| **Реципрокность** | Бесплатный шаблон / гайд / 5-дневный пробник без карты |
| **Принадлежность** | «1 247 владельцев салонов красоты уже создали сайт» — конкретная группа |
| **Loss aversion** | «Каждый день без сайта — 3-7 потерянных клиентов» (страх потерять) |
| **Anchoring** | Рядом с ценой 990 ₽ показываем «обычно студия берёт 80 000 ₽» |

### 0.4 Правила, которых не нарушаем

- ❌ Никаких stock-фотографий с улыбающимися моделями на фоне ноутбука
- ❌ Никаких слов «инновационный», «революционный», «передовой», «уникальный» (без доказательств)
- ❌ Никаких длинных параграфов — максимум 3 строки текста подряд
- ❌ Никаких форм с 5+ полями — максимум email + один клик
- ❌ Никакого «свяжитесь с нами» без объяснения «зачем»
- ❌ Никаких ссылок ведущих с лендинга в первой половине прокрутки

### 0.5 Главная метрика

**Конверсия лендинг → пробник (free trial signup)**. Цель: **5-7%** для cold-трафика, **10-15%** для тёплого (reach пользователей которые видели нас ранее).

## 1. Правило 5 секунд (hero-секция)

### 1.1 Что должно быть на первом экране без прокрутки

Когда пользователь открывает сайт, у нас **ровно 5 секунд** чтобы он понял:
1. **Что мы делаем** (одно предложение)
2. **Для кого** (одна фраза)
3. **Что нужно сделать чтобы попробовать** (одна кнопка)
4. **Что это безопасно** (один visual proof)

### 1.2 Структура hero-секции

### 1.3 Варианты главного заголовка (для A/B-тестирования)

Берём 3-5 вариантов, тестируем по очереди, измеряем конверсию в клик «Создать сайт бесплатно».

| Вариант | Тип | Психологический трюк |
|---|---|---|
| **A.** «Сайт для вашего бизнеса за 30 минут — без программиста» | Конкретный + Pain | Время + отсутствие зависимости |
| **B.** «Опишите бизнес. Получите готовый сайт. На русском, под 152-ФЗ» | Простой процесс | Минимизация шагов |
| **C.** «1 247 малых бизнесов уже сделали сайт на Omnia.AI за вечер» | Социальный proof + конкретика | Принадлежность |
| **D.** «AI-конструктор сайтов, который понимает по-русски» | УТП (vs Tilda) | Уникальность |
| **E.** «Запустите сайт сегодня — без дизайнера, без программиста, без головной боли» | Pain × 3 | Loss aversion |

### 1.4 Подзаголовок (одинаковый для всех вариантов)

> «От лендинга до интернет-магазина. Опишите что нужно — AI соберёт. Поддержка на русском, оплата картой РФ, всё по закону.»

### 1.5 Главный CTA (Call To Action)

**Текст кнопки:** `Создать сайт бесплатно →`

❌ НЕ «Зарегистрироваться», «Начать», «Попробовать» — слишком абстрактно
✓ «Создать сайт бесплатно» — глагол + что получишь + цена (бесплатно)

**Под кнопкой micro-copy:**
> «5 дней без оплаты · банковская карта не нужна · отменить можно одним кликом»

### 1.6 Вторичный CTA

**Текст:** `Посмотреть 2-минутное демо →`

Открывает модалку с видео-демонстрацией (не уводит со страницы — сохраняем pixel/cookie).

### 1.7 Visual proof в hero

Один из вариантов:
- **Видео 30-60 сек** auto-play (без звука) — показываем как пользователь печатает «Сайт для салона красоты, услуги, цены, форма записи» → AI собирает сайт в реальном времени
- **Интерактивная анимация** — печатающийся курсор + появляющиеся блоки
- **Скриншот готового сайта** + animated arrow к кнопке CTA

### 1.8 Trust signals в hero

Прямо под кнопкой, мелким шрифтом, без давления:

```
★ Без банковской карты    ★ 152-ФЗ соответствие    ★ Хостинг в РФ
★ Поддержка в Telegram     ★ Отмена в 1 клик       ★ Деньги назад 30 дней
```

## 3. Секция «Боль» (Problem Agitation)

### 3.1 Структура

```
Заголовок: Знакомо?

[Иконка]  «Студия просит 80 000 ₽ за лендинг и 6 недель ожидания»
[Иконка]  «Tilda требует разобраться в 47 настройках перед первым блоком»
[Иконка]  «Фрилансер пропал на третий день после оплаты»
[Иконка]  «А вам нужен сайт — на этой неделе»

Резюме: Запустить сайт сегодня — должно быть просто. И возможно.
```

### 3.2 Что важно

- **3-4 пункта** — не больше. Каждый = реальная боль из исследования аудитории
- **Сразу узнаваемо** — клиент должен подумать «это же про меня»
- **Без преувеличений** — без «вы теряете миллионы»
- **Иконки или эмодзи** — лёгкое визуальное разнообразие

### 3.3 Варианты болей по сегментам

Если знаем источник трафика (UTM-метки), показываем разные:

**Для владельцев кафе (трафик с «сайт для кафе»):**
- «Конкуренты в Яндекс.Картах с сайтом — заметнее»
- «Меню в Excel-файле клиенты не открывают»
- «Доставка без онлайн-заказа = телефонные часы»

**Для юристов (трафик с «сайт юриста»):**
- «Клиенты гуглят перед визитом — без сайта вы невидимы»
- «Доверие = первое впечатление = современный сайт»
- «Конкуренты уже есть в выдаче. Вы — нет»

**Для красоты (трафик с «сайт мастера маникюра»):**
- «Запись через Direct = 80% потерянных запросов на выходных»
- «Прайс в Stories через неделю никто не найдёт»
- «Карта услуг + онлайн-запись = +30% новых клиентов»

## 18. Мобильная версия (mobile-specific)

### 18.1 Принципы

- **Mobile-first design** — сначала проектируем под телефон, потом desktop
- **Один column** — никаких 3×3 сеток, всё в столбец
- **Большие кнопки** — минимум 48×48 px tap target
- **Минимум forms** — на главном CTA только email или сразу phone-auth
- **Свайп-карусели** для шаблонов и отзывов (нативно для пальца)
- **Виртуальная клавиатура учитывается** — CTA не должен закрываться

### 18.2 Mobile-only элементы

- **Sticky-bottom CTA** (см. 17.2)
- **Click-to-call** — кликабельный номер телефона в footer
- **Click-to-Telegram** — `tg://...` ссылка прямо открывает чат
- **Минимум видео** — желательно GIF / WebP анимации (легче на 3G)

### 18.3 Performance на мобиле

- LCP (Largest Contentful Paint) < 2.5 сек
- FID (First Input Delay) < 100 мс
- CLS (Cumulative Layout Shift) < 0.1
- Total page size < 1 MB на первой загрузке
- Lazy-load всех изображений ниже первого экрана

## 19. Скорость загрузки (Page speed)

### 19.1 Почему критично

- Google Search: каждые **+100 мс** = **−1% конверсии**
- 53% мобильных пользователей **уходят** если страница грузится > 3 сек
- В РФ 30% трафика — мобильный 3G/4G

### 19.2 Технические требования

- **Time to First Byte** < 200 мс (CDN + хостинг в РФ)
- **First Contentful Paint** < 1.5 сек
- **Largest Contentful Paint** < 2.5 сек
- **Total Blocking Time** < 200 мс
- **Cumulative Layout Shift** < 0.1
- **Speed Index** < 3.0 сек

### 19.3 Что делаем

- HTML/CSS inline для critical path (выше fold)
- Изображения в WebP/AVIF с lazy-loading
- Видео: poster image + native lazy controls
- Шрифты: subset, woff2, font-display: swap
- JS: code splitting, deferred load для не-критичных скриптов
- Третьесторонние скрипты (аналитика, чат) — отложить до user interaction

## 20. Микро-копирайтинг (Microcopy)

### 20.1 Где меняет конверсию

Маленькие тексты под кнопками / в формах могут поднять конверсию на 10-30%.

### 20.2 Правила

**Кнопки CTA:**
- ❌ «Отправить», «Зарегистрироваться», «Начать»
- ✓ «Получить мой сайт», «Создать бесплатно», «Забрать пробник»

**Поля формы:**
- ❌ «Email» (просто плейсхолдер)
- ✓ «Email — пришлём шаблоны под ваш бизнес»

**Лоадеры:**
- ❌ «Загружается...»
- ✓ «AI подбирает дизайн для вашего кафе... ⏳»

**Ошибки:**
- ❌ «Ошибка валидации»
- ✓ «Этот email уже используется. Войти? [Войти] [Сбросить пароль]»

**Подтверждение:**
- ❌ «Сохранено»
- ✓ «Готово! Сайт сохранён. Хотите опубликовать сейчас? [Опубликовать]»

**Cookie banner:**
- ❌ «Этот сайт использует cookies»
- ✓ «Мы используем cookies чтобы запомнить ваши настройки. Ок? [Понятно] [Только нужные]»

### 20.3 Tone of voice

- **Дружелюбный, но не панибратский** — «ты» в продукте, «вы» на лендинге
- **Без жаргона** — никаких «коммитим», «инстансы», «фолбэк»
- **Конкретный** — числа, имена, время вместо «много», «быстро», «надёжно»
- **Активный залог** — «Вы создаёте» вместо «Создаётся вами»
- **С эмоциями** — лёгкие шутки, эмодзи, восклицания (в меру)

## 21. План A/B-тестирования

### 21.1 Что тестируем (в порядке приоритета)

| # | Элемент | Гипотеза | Ожидаемый рост |
|---|---|---|---|
| 1 | Hero заголовок (5 вариантов) | Конкретный с цифрой даст +20-40% | +20-40% |
| 2 | CTA текст («Создать» vs «Попробовать» vs «Начать») | «Создать сайт бесплатно» — лучший | +5-15% |
| 3 | Цвет CTA (синий vs оранжевый vs фиолетовый) | Контраст с фоном важнее цвета | +3-8% |
| 4 | Видео-демо vs анимация vs скриншот в hero | Видео даёт +12-25% | +12-25% |
| 5 | Trust bar: логотипы vs цифры vs медиа | Цифры конкретнее на cold-трафике | +5-10% |
| 6 | Pricing: 3 карточки vs 5 карточек | 3 — меньше cognitive load | +8-18% |
| 7 | FAQ: аккордеон vs полностью раскрытый | Аккордеон при > 8 вопросах | +3-7% |
| 8 | Exit-intent popup: показывать / не показывать | Конверсия +2-5% при не aggressive | +2-5% |

### 21.2 Правила тестирования

- Один тест за раз (или несколько не пересекающихся секций)
- Минимум 1000 уникальных посетителей на вариант для статзначимости
- Минимум 7 дней (учесть еженедельные паттерны)
- Конверсия меряется в **signup**, не в кликах
- При уверенности > 95% (p < 0.05) — катим винера на 100%

## 23. Аналитика и метрики

### 23.1 Главные метрики

| Метрика | Что меряет | Цель |
|---|---|---|
| **Conversion rate** | Лендинг → пробник | 5-7% (cold), 10-15% (warm) |
| **Activation rate** | Пробник → первый созданный сайт | 60-75% |
| **Trial-to-paid** | Пробник → платящий | 8-12% |
| **Bounce rate** | Закрытие после 1 страницы | < 45% |
| **Time on page** | Среднее время на лендинге | > 90 сек |
| **Scroll depth** | До какой секции долистывают | > 50% |
| **CTA click rate** | Клики на «Создать бесплатно» | > 8% |
| **Demo interactions** | Сколько ввели в интерактивный демо | > 25% |

### 23.2 Инструменты

- **Яндекс.Метрика** — основная аналитика, тепловые карты, вебвизор
- **UTM-метки на ВСЕМ** — `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`
- **Event tracking** — каждое CTA, каждая вкладка FAQ, каждый клик на шаблон
- **Funnel analysis** — путь пользователя от первой страницы до оплаты

### 23.3 Что обязательно отслеживать

- Источник трафика (Direct / VK / Telegram / органика / прямой)
- Устройство (mobile / desktop / tablet)
- Регион (Москва / Питер / регионы / другие страны)
- Сессия: первая или повторная
- Время до конверсии (быстрый = горячий лид, медленный = sales-cycle)

## 25. Психологические ловушки которых избегаем

### 25.1 Anti-patterns на лендинге

- ❌ **Auto-play видео со звуком** → раздражает, закрывают вкладку
- ❌ **Длинный stock-видео в hero** → 30+ сек не смотрят
- ❌ **Carousel в hero** → ослабляет каждое сообщение
- ❌ **«Свяжитесь с менеджером»** как главный CTA → высокий порог
- ❌ **Цена «по запросу»** → пользователь уходит сравнивать с теми, у кого цены открыты
- ❌ **5+ полей в форме регистрации** → каждое поле = −7% конверсии
- ❌ **Капча на регистрации** → −12% конверсии
- ❌ **Pop-up через 5 сек после захода** → −20% конверсии (раздражение)
- ❌ **«Загрузка не работает в IE»** → не нужно поддерживать, но не предупреждать ругательно
- ❌ **Слова «революционный», «инновационный»** без доказательств → доверие падает

### 25.2 Признаки честного продающего лендинга

- ✓ **Цены видны сразу** (не «по запросу»)
- ✓ **Демо работает без регистрации**
- ✓ **Отзывы с реальными именами и фото**
- ✓ **Сравнение с конкурентами честное** (не врать про Tilda)
- ✓ **FAQ закрывает реальные возражения** (не маркетинговый bullshit)
- ✓ **Гарантия возврата без скрытых условий**
- ✓ **Реквизиты компании на сайте**

## 26. Краткая шпаргалка по структуре

Если выкинуть всё лишнее — лендинг должен состоять из этих **10 блоков в этом порядке**:

```
1. Hero (заголовок + подзаголовок + CTA + видео-демо)
2. Trust bar (логотипы клиентов / цифры / медиа)
3. Боль (3-4 узнаваемых проблемы клиента)
4. Решение (одно предложение + 3 столбца)
5. Интерактивное демо (попробуйте прямо здесь)
6. Как это работает (4 шага)
7. Что получите (6 ключевых выгод)
8. Use cases (12 ниш с шаблонами)
9. Сравнение (мы vs студия vs Tilda vs фрилансер)
10. Калькулятор экономии
11. Отзывы + кейсы
12. Витрина сайтов
13. Тарифы (3 карточки + ссылка на все)
14. FAQ (15 вопросов)
15. Финальный CTA
16. Footer
```

Плюс **постоянные элементы**: sticky header, sticky bottom CTA на мобиле, live-чат / AI-помощник, exit-intent на desktop.

## 28. Финальный совет

**Один лендинг не сделает всю продажу.** Конверсия = воронка из:

1. Реклама (хороший таргет + чистые запросы)
2. Лендинг (всё что выше)
3. Регистрация (низкое трение, ≤ 3 шага)
4. Onboarding (первый сайт за 30 минут с подсказками)
5. Welcome-серия (email-цепочка на 7 дней)
6. Saport (Telegram, отвечают за 30 минут)
7. Upgrade-моменты (когда исчерпан пробник)
8. Реферальная программа (для платящих)

**Лендинг = 30% результата. Onboarding и saport = 70%.** Если человек попробовал и за первые 10 минут не получил wow-эффекта от продукта — никакой лендинг не спасёт.
